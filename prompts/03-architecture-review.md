# Prompt — Architecture Review

Faça uma revisão arquitetural completa do repositório.

Avalie:

- boundaries;
- acoplamento;
- multi-tenancy;
- segurança;
- autorização;
- auditoria;
- consistência;
- dependências;
- observabilidade;
- filas;
- tratamento de erro;
- testes.

Classifique achados como:

- crítico;
- alto;
- médio;
- baixo.

Para cada item:

- problema;
- risco;
- evidência;
- recomendação;
- arquivos afetados.

Não faça alterações até apresentar o diagnóstico.
