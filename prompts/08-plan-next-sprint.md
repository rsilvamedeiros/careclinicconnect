# Prompt — Planejar Próxima Sprint

Leia:

- roadmap;
- backlog;
- PRD;
- milestones;
- estado atual do código.

Monte a próxima sprint priorizando:

1. dependências;
2. risco;
3. valor;
4. validação do produto.

Entregue:

- objetivo da sprint;
- histórias;
- tarefas;
- critérios de aceite;
- dependências;
- riscos;
- ordem de execução.

Evite incluir trabalho que não contribua diretamente para o milestone atual.
