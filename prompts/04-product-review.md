# Prompt — Product Review

Analise uma feature sob perspectiva de produto antes de implementá-la.

Feature:

`<FEATURE>`

Responda:

1. qual problema resolve?
2. quem usa?
3. onde entra na jornada?
4. qual comportamento esperado?
5. quais edge cases?
6. quais métricas?
7. quais permissões?
8. quais dados sensíveis?
9. como evitar configuração específica para um cliente?
10. como essa feature diferencia o CareClinicConnect de um CRUD tradicional?
