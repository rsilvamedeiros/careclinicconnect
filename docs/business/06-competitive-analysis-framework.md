# Framework de Análise Competitiva

## Dimensões

Avaliar concorrentes por:

- agenda;
- prontuário;
- CRM;
- financeiro;
- automação;
- WhatsApp;
- experiência do paciente;
- fotos;
- procedimentos;
- multiunidade;
- analytics;
- API;
- IA;
- integrações;
- UX;
- onboarding;
- pricing.

## Pergunta importante

Não perguntar apenas:

"Que feature o concorrente tem?"

Perguntar:

"Qual problema ele resolve melhor e onde a experiência ainda quebra?"

## Resultado esperado

Criar matriz:

```text
Concorrente | ICP | Força | Fraqueza | Diferencial | Oportunidade
```

## Regra

Não copiar interface ou feature sem entender o problema original.
