# Agentes e Assistentes

## Reception Agent
- consultar disponibilidade;
- responder FAQ;
- registrar lead;
- solicitar dados;
- sugerir agendamento.

## Follow-up Agent
- identificar pacientes elegíveis;
- iniciar fluxo;
- registrar respostas;
- transferir para humano.

## Clinical Documentation Assistant
- transcrever quando autorizado;
- resumir;
- estruturar;
- gerar rascunho.

O profissional confirma antes da gravação final.

## Operations Analyst
- monitora indicadores;
- identifica ociosidade;
- aponta cancelamentos;
- gera insights.

## Guardrails

Todo agente deve possuir:

- escopo;
- ferramentas autorizadas;
- permissões;
- limite de ações;
- confirmação humana para ações críticas;
- logs.
