# Diferenciais do CareClinicConnect

## Timeline 360º

Uma visão integrada de:

- leads;
- mensagens;
- consultas;
- documentos;
- procedimentos;
- imagens;
- pagamentos;
- retornos.

## Workflow Engine

Exemplo:

```text
procedimento concluído
  -> aguardar 24h
  -> enviar orientação
  -> aguardar 6 dias
  -> solicitar atualização
  -> criar tarefa para profissional se houver condição configurada
```

## Clinic Intelligence

- horários com maior risco de no-show;
- pacientes sem retorno;
- leads esquecidos;
- queda de conversão;
- agenda subutilizada.

## Connected Patient Journey
