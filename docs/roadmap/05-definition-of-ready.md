# Definition of Ready

Uma feature está pronta para desenvolvimento quando possui:

- problema definido;
- usuário definido;
- escopo;
- critérios de aceite;
- dependências;
- permissões;
- dados necessários;
- impacto de segurança;
- impacto multi-tenant;
- analytics;
- wireframe ou descrição de UX quando necessário.

## Perguntas obrigatórias

1. Quem precisa disso?
2. Por que precisa?
3. Como sabemos que funcionou?
4. Pode vazar dados entre tenants?
5. Gera dados sensíveis?
6. Precisa de audit trail?
7. Deve gerar evento?
8. Pode ser assíncrona?
