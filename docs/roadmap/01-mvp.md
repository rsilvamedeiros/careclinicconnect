# MVP

## Objetivo

Validar se clínicas do nicho inicial pagam por uma plataforma integrada de operação + CRM + jornada.

- marketplace;
- app nativo completo;

- microserviços;

- contabilidade;
- estoque avançado.

## Critério de sucesso

Operar o fluxo:

`lead -> avaliação -> orçamento -> procedimento -> pós -> retorno`

sem depender de múltiplas ferramentas paralelas.
