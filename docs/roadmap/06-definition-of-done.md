# Definition of Done

Uma feature só está concluída quando:

- requisitos atendidos;
- código revisado;
- testes passando;
- autorização validada;
- isolamento por tenant validado;
- erros tratados;
- logs adequados;
- documentação atualizada;
- métricas/eventos implementados quando aplicável;
- migrations versionadas;
- feature flag usada quando necessária;
- UX responsiva;
- acessibilidade mínima validada.
