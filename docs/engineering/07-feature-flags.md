# Feature Flags

## Uso

Feature flags podem controlar:

- lançamento gradual;
- beta;
- tenant piloto;
- rollback funcional;
- módulos premium.

## Não usar para

- esconder código morto indefinidamente;
- substituir autorização.

## Contexto

Possíveis dimensões:

- tenant;
- plan;
- user;
- environment.

## Governança

Toda flag deve ter:

- owner;
- data de criação;
- objetivo;
- plano de remoção.
