# Design System

## Objetivos

- consistência;
- acessibilidade;
- velocidade;
- reutilização;
- identidade própria.

## Foundations

- typography;
- spacing;
- radius;
- elevation;
- breakpoints;
- semantic tokens;
- motion.

## Componentes prioritários

- Button
- Input
- Select
- Combobox
- DatePicker
- Calendar
- Modal
- Drawer
- Tabs
- Table
- DataGrid
- Badge
- Avatar
- Timeline
- Card
- EmptyState
- Toast
- FormField
- PermissionGuard
- Skeleton

## Padrões complexos

- PatientHeader;
- AppointmentCard;
- LeadCard;
- TimelineItem;
- ClinicalDocumentViewer;
- MetricCard;
- FilterBar;
- CommandPalette.

## Storybook

Todo componente reutilizável relevante deve possuir story.

## Acessibilidade

- navegação por teclado;
- labels;
- focus visível;
- contraste;
- leitores de tela;
- estados claros.
