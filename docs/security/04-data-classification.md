# Classificação de Dados

## Public

Exemplos:
- páginas institucionais;
- informações públicas da clínica.

## Internal

Exemplos:
- configurações operacionais não sensíveis;
- documentos internos.

## Confidential

Exemplos:
- dados comerciais;
- relatórios;
- informações financeiras internas.

## Restricted / Sensitive

Exemplos:
- dados de saúde;
- prontuários;
- documentos pessoais;
- fotos clínicas;
- credenciais.

## Regra

Quanto maior a classificação:

- menor acesso;
- maior auditoria;
- maior proteção;
- menor exposição em logs.
